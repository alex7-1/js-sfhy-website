# 江苏三丰鸿业工业有限公司官网

江苏三丰鸿业工业有限公司官方网站，包含公司简介、精密刀模与非标自动化两大事业部及产品案例。

## 网站结构

- `index.html`：公司官网首页
- `company.html`：公司简介、经营增长与团队能力
- `precision-dies.html`：精密刀模事业部
- `rotary-dies.html`：高精密圆刀模产品页
- `flat-dies.html`：平刀模产品页
- `automation.html`：非标自动化事业部
- `automation-lines.html`：非标自动化包装机产品页
- `ai-vision.html`：AI 视觉检测产品页
- `intralogistics.html`：智能输送与机器人产品页
